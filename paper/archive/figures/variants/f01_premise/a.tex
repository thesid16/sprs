% f01_premise variant a -- two reduction trees over the SAME leaf vector.

%       N=1000, M=1024, fp64, profile=signed; the 64-bit result is the leading
%       64 bits of the SHA-256 the harness records over the reduced vector
%       ("hash" field). Scope wording from \GpuHardware/\GpuStack and the
%       scope paragraph of sec:results-premise: above G=2 the reshape sweep is
%       the gloo/CPU backend, because NCCL needs one rank per device.
%       The count of cross-rank additions per element is G-1, exact; the
%       leaf row is schematic (8 boxes stand for the N=1000 leaves).
% Strategy: the mechanism, at the smallest possible scale -- one leaf vector,
% two partitions, two association orders, two different 64-bit results printed
% side by side with the first divergent nibble boxed. b argues by count, c by
% dataflow, d by magnitude; this one shows the object itself.
% Colour: the G=2 tree is the reference order (spBlue); the G=4 tree is the
% reshaped, divergent order (spVerm). The shared leaf row is spGreen -- it is
% the one thing confirmed identical. Shape still carries the encoding: the two
% trees differ in depth and the two digests differ in glyphs, so greyscale
% loses nothing.
